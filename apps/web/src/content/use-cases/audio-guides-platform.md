Built a full-stack map platform for the founders of izi.TRAVEL, powering [tmatic.travel](https://tmatic.travel). The system hosts 20 000+ audio tours and 500 000+ stories worldwide. Developed a CMS for curating content, a responsive public map view (Angular, Mapbox) with 2D and 3D modes, and an API for external partners. Includes a dedicated indoor mode for museums and cultural venues to explore audio content without maps. Backend (Java Spring, PostGIS) ensures seamless delivery for travelers and cultural institutions globally.
