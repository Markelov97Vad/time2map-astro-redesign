Built a platform for [LandTracing](https://landtracing.com) to automate land certificate generation across the US. Designed a system that analyzes parcels against protected and restricted zones using aggregated data from multiple sources. Developed a public interface for clients to search and order certificates (React, Figma) and an admin panel to validate and process orders. Backend (Python FastAPI, QGIS Server) automates spatial analysis and PDF certificate creation. Delivered a scalable solution that replaced manual workflows with an end-to-end digital process.
