Built a full-stack geospatial platform for organizing crop-field imagery and observations for autonomous-weeding workflows in the Netherlands. A React and MapLibre interface lets growers browse Dutch agricultural parcels by season, claim fields, filter observations and manage field imagery. The Node.js backend combines PostGIS field geometry with a user-owned W3DS/eVault data layer, keeping access and ownership under growers’ control. Role-based sharing, eID Wallet authentication, real-time synchronization and a Playwright-powered PixelFarming import pipeline support the workflow from field capture to a searchable image library.
